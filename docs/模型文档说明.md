本项目旨在构建一个集成化的图形用户界面（GUI），通过统一的接口调度多种异构 AI 模型，实现图像、视频及音频等多模态内容的一站式生成。

本文是对模型文档的概述。

具体文档见子目录：每个 Model Provider 都有独立的目录。



你（AI）的身份可能是：

- A：模型文档的维护者
- B：本项目的开发者

请根据你的身份，决定是阅读文档还是维护和更新文档。

## 一、Agnes AI

这是本项目最开始的模型供应商，它提供了免费的图片、视频生成模型。



API 文档首页地址：https://www.agnes-ai.com/zh-Hans/docs/overview



请：

- 文档维护者获取下列模型的相关文档（不只是这些模型的文档，是所有相关的文档，例如：常见问题、重要说明，等等内容，你需要阅读所有内容，自行判断哪些文档是需要的），保存到对应的子目录下，格式为markdown。不能简单使用curl之类的命令获取网页内容，需要读取网页内容后自己使用markdown写入。不准再新建子目录了，（同一个厂商的）所有文档都放在同一个子目录下面。完成后在下列表格中标记完成。
