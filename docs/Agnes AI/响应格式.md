## 图片生成响应

URL 输出：

```json
{
  "created": 1780000000,
  "data": [
    {
      "url": "https://storage.googleapis.com/agnes-aigc/xxx.png",
      "b64_json": null,
      "revised_prompt": null
    }
  ]
}
```

Base64 输出：

```json
{
  "created": 1780000000,
  "data": [
    {
      "url": null,
      "b64_json": "iVBORw0KGgoAAAANSUhEUgAA...",
      "revised_prompt": null
    }
  ]
}
```

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `created` | integer | 请求创建时间戳。 |
| `data` | array | 生成结果列表。 |
| `data[].url` | string / null | URL 输出时为图片地址；Base64 输出时通常为 `null`。 |
| `data[].b64_json` | string / null | Base64 输出时为图片数据；URL 输出时通常为 `null`。 |
| `data[].revised_prompt` | string / null | 修正后的提示词；没有时为 `null`。 |

## 视频创建任务响应

`agnes-video-v2.0`、`agnes-video-2.5`、`agnes-video-2.5-flash` 都是异步任务模型。创建成功后应保存 `video_id`。

```json
{
  "id": "task_YOUR_TASK_ID",
  "task_id": "task_YOUR_TASK_ID",
  "video_id": "video_YOUR_VIDEO_ID",
  "object": "video",
  "model": "agnes-video-2.5",
  "status": "queued",
  "progress": 0,
  "created_at": 1786900000,
  "seconds": "5",
  "size": "720P"
}
```

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `id` | string | 任务 ID，通常与 `task_id` 表示同一任务。 |
| `task_id` | string | 异步生成任务 ID。 |
| `video_id` | string | 视频 ID，推荐用于轮询结果。 |
| `object` | string | 对象类型，通常为 `video`。 |
| `model` | string | 当前任务使用的模型。 |
| `status` | string | 初始状态通常为 `queued`。 |
| `progress` | integer | 任务进度，范围 `0-100`。 |
| `created_at` | integer | 任务创建时间，Unix 时间戳。 |
| `seconds` | string | 视频时长。 |
| `size` | string | 输出分辨率档位或实际输出尺寸。 |

## 视频查询完成响应

任务完成后，最终视频地址在 `metadata.url`。

```json
{
  "id": "task_YOUR_TASK_ID",
  "video_id": "video_YOUR_VIDEO_ID",
  "task_id": "task_YOUR_TASK_ID",
  "object": "video",
  "model": "agnes-video-2.5",
  "status": "completed",
  "progress": 100,
  "created_at": 1786900000,
  "completed_at": 1786900120,
  "seconds": "5",
  "size": "720P",
  "metadata": {
    "url": "https://example.com/generated/video.mp4"
  }
}
```

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `status` | string | 只有 `completed` 才表示生成成功。 |
| `completed_at` | integer / null | 完成时间；未完成时可能为 `null`。 |
| `metadata` | object / null | 结果元数据；未完成或失败时可能为空。 |
| `metadata.url` | string | 成片地址，仅在 `status: "completed"` 后可交付。 |
| `metadata.size_mapping` | object / null | 尺寸标准化信息；主要用于排查实际输出与请求尺寸不一致。 |
| `error` | object / null | 失败时包含错误信息。 |

## 视频失败响应

```json
{
  "id": "task_YOUR_TASK_ID",
  "video_id": "video_YOUR_VIDEO_ID",
  "task_id": "task_YOUR_TASK_ID",
  "object": "video",
  "model": "agnes-video-2.5",
  "status": "failed",
  "progress": 100,
  "metadata": null,
  "error": {
    "message": "Invalid reference media"
  }
}
```

| 状态 | 含义 | 前端/服务端处理 |
| --- | --- | --- |
| `queued` | 排队中 | 继续轮询，不显示失败。 |
| `in_progress` | 生成中 | 展示进度，继续轮询。 |
| `completed` | 成功 | 使用 `metadata.url`。 |
| `failed` | 失败 | 读取 `error.message` 并停止轮询。 |

## 轮询建议

| 项目 | 建议 |
| --- | --- |
| 轮询间隔 | `agnes-video-2.5` 文档建议每 `1-2` 秒查询一次。 |
| 查询参数 | 2.5 系列所有模式推荐带 `model_name`。 |
| 停止条件 | `status` 为 `completed` 或 `failed`。 |
| 超时控制 | 生产环境必须设置最大轮询时长。 |
| 可交付判断 | 不要只看 HTTP 200；必须同时确认 `status: "completed"` 和 `metadata.url` 存在。 |
