## 接入边界

| 项目 | 规则 |
| --- | --- |
| Base URL | `https://apihub.agnes-ai.com/v1` |
| 鉴权 | 所有请求都需要 `Authorization: Bearer YOUR_API_KEY`。 |
| API Key 安全 | API Key 只能放在服务端或安全配置中；不要写入前端代码、日志、截图、公开文档或公开仓库。 |
| OpenAI 兼容性 | Agnes AI 采用 OpenAI 风格接口；迁移时通常需要替换 Base URL、API Key 和模型名称。 |
| 媒体 URL | 图片、音频、视频 URL 必须能被 Agnes AI 服务公开访问，不能依赖登录、Cookie、内网地址或短期过期链接。 |
| 长任务 | 图片和视频生成可能耗时较长，客户端需要设置足够超时，并对网络错误和 `429` 做退避重试。 |

## 图片模型关键规则

| 规则 | 正确做法 | 常见错误 |
| --- | --- | --- |
| 输出格式字段位置 | URL 输出使用 `extra_body.response_format: "url"`；图生图 Base64 输出使用 `extra_body.response_format: "b64_json"`。 | 把 `response_format` 放在请求体顶层。 |
| 文生图必填字段 | 提供 `model`、`prompt`、`size`。 | 文生图时传空的 `image` 字段。 |
| 图生图输入 | 在 `extra_body.image` 中传入图片 URL 或 Data URI Base64。 | 把输入图放在顶层 `image`，或没有传 `extra_body.image`。 |
| 多图合成输入 | 在 `extra_body.image` 中传入多张参考图。 | 不说明每张参考图在生成中的作用。 |
| 图生图标签 | 不需要 `tags: ["img2img"]`。 | 为了触发图生图额外传 `tags`。 |
| 尺寸控制 | 推荐使用 `1K`、`2K`、`3K`、`4K` 与 `ratio` 组合。 | 把 `1920x1080`、`2560x1440` 等显示器尺寸当成模型原生尺寸。 |
| Base64 输出 | 文生图可以用 `return_base64: true`；图生图使用 `extra_body.response_format: "b64_json"`。 | 文生图和图生图混用同一套 Base64 参数。 |

## 视频模型关键规则

| 模型 | 规则 |
| --- | --- |
| `agnes-video-v2.0` | 异步任务；先 `POST /v1/videos` 创建任务，再通过 `video_id` 查询结果。 |
| `agnes-video-v2.0` | `num_frames` 必须小于等于 `441`，并符合 `8n + 1`；视频时长按 `num_frames / frame_rate` 计算。 |
| `agnes-video-v2.0` | 图生视频使用顶层 `image`；关键帧动画使用 `extra_body.image` 和 `extra_body.mode: "keyframes"`。 |
| `agnes-video-2.5` | `mode` 必须为 `text`、`keyframe` 或 `reference`。 |
| `agnes-video-2.5` | `seconds` 使用字符串 `"4"` 到 `"12"`；`n` 当前固定为 `1`。 |
| `agnes-video-2.5` | 所有模式推荐使用 `GET /agnesapi?video_id=<VIDEO_ID>&model_name=agnes-video-2.5` 查询；不带 `model_name` 的查询仅适合 `text` 模式。 |
| `agnes-video-2.5-flash` | `size` 必须是字符串 `"720P"`。 |
| `agnes-video-2.5-flash` | `reference` 模式最多 5 张图片、3 段音频；不要传有效的 `videos` 内容。 |
| `agnes-video-2.5-flash` | `16:9` 的 720P 实测输出为 `1280x704`，展示和验收时应以实际响应或文件为准。 |

## `agnes-video-2.5` 模式互斥规则

| `mode` | 必需媒体 | 不允许字段 | 说明 |
| --- | --- | --- | --- |
| `text` | 无 | `first_frame`、`last_frame`、`images`、`audios`、`videos` | 纯文本生成视频。 |
| `keyframe` | `first_frame` 和 `last_frame` 至少一个 | `images`、`audios`、`videos` | 使用首帧、尾帧或首尾帧控制起止构图。 |
| `reference` | `images`、`audios`、`videos` 至少一类非空 | `first_frame`、`last_frame` | 把素材作为内容、风格、动作或节奏参考。 |

## 开发实现优先级

| 优先级 | 内容 |
| --- | --- |
| 1 | API Key 安全、Base URL、模型 ID、Endpoint 拼接必须先做对。 |
| 2 | 图片模型先支持 URL 输出，再支持 Base64 输出、图生图、多图合成。 |
| 3 | 视频模型必须实现任务创建、保存 `video_id`、轮询、完成/失败状态处理。 |
| 4 | 对 `400`、`401`、`402`、`404`、`429`、`5xx` 给出可读错误提示。 |
| 5 | 对 `429`、网络错误、`504`、`524` 等情况实现退避重试和最大等待时间。 |
