# Agnes AI 错误码

资料更新时间：2026-09-03

资料来源：https://wiki.agnes-ai.com/zh-Hans/docs/code

## HTTP 错误码总表

| 状态码 | 含义 | 常见原因 | 建议处理 |
| --- | --- | --- | --- |
| `400` | 请求参数无效 | JSON 格式错误、缺少必填参数、字段类型错误、上下文过长、视频生成参数错误 | 检查必填字段、JSON、参数类型、FPS、时长、分辨率和宽高比。 |
| `401` | 认证失败 | API Key 错误、过期、缺失、Header 不正确、Key 属于其他账户 | 重新复制 Key，确认 `Authorization: Bearer YOUR_API_KEY` 格式。 |
| `402` | 余额或配额不足 | 账户余额不足、Token Plan 配额不足、订阅异常或未生效 | 检查余额、Token Plan、订阅状态；降低单次请求成本或升级套餐。 |
| `403` | 无权访问资源 | Key 或账户没有模型权限、企业认证/订阅未生效、来源受限 | 检查账户权限、Key 类型、网络环境；必要时联系支持。 |
| `404` | 地址、路径或资源不存在 | Base URL 错误、路径错误、重复拼接 `/v1`、模型名或任务 ID 错误 | 检查 Base URL、Endpoint、模型 ID、视频 `video_id`。 |
| `405` | HTTP 方法不支持 | 需要 POST 时用了 GET，或需要 GET 时用了 POST | 按文档使用正确 HTTP 方法。 |
| `408` | 请求超时 | 网络不稳定、请求过大、图像/视频任务耗时长、客户端超时太短 | 缩短输入、降低规格、增加客户端超时、重试。 |
| `409` | 请求状态冲突 | 重复提交、同一请求处理中、资源状态不允许操作 | 避免重复提交，等待任务完成，增加幂等或重复提交保护。 |
| `413` | 请求体过大 | Base64 图像过大、上下文过长、上传文件过大 | 压缩内容、分批提交、降低图片大小，优先使用公共 URL。 |
| `415` | 媒体类型不支持 | Content-Type 错误、文件格式不支持、媒体格式不符合要求 | 检查 `Content-Type`，图片优先 PNG/JPG/JPEG/WEBP。 |
| `422` | 参数值不符合模型要求 | seed、分辨率、宽高比、FPS 超限；图片 URL 不可访问；Base64 无效 | 根据错误消息修正参数，检查媒体 URL 和 Base64 完整性。 |
| `429` | 请求频率过高 | 超过 RPM、并发过多、自动重试太密 | 降低请求频率，控制并发，等待窗口恢复，使用指数退避。 |
| `431` | 请求 Header 过大 | Header、Authorization、Cookie 或自定义 Header 过大 | 移除不必要 Header，检查 Authorization。 |
| `499` | 客户端提前关闭请求 | 客户端超时、浏览器或工具中断、网络切换 | 增加超时，避免中断长任务，必要时改用异步任务或轮询。 |
| `500` | 服务端内部错误 | 请求参数触发服务异常、图像/视频尺寸不符合要求、上游异常 | 检查参数；图像尺寸需为 16 的倍数，视频尺寸需为 64 的倍数；重试或联系支持。 |
| `502` | 网关未收到有效上游响应 | 网络、DNS、代理或上游波动 | 检查网络、代理、DNS，稍后重试。 |
| `503` | 服务暂时不可用 | 模型名错误、模型列表失败、路由/回退模型配置问题、服务繁忙 | 检查模型名、路由和回退配置，稍后重试。 |
| `504` | 网关等待上游超时 | 上游响应慢、图像/视频/长上下文耗时过长、负载高 | 缩短输入、降低生成规格、减少并发、增加超时。 |
| `520` | 未知错误 | 网络、代理、DNS 或上游临时波动 | 重试，检查网络/代理/DNS；持续失败时提交完整错误信息。 |
| `522` | 连接上游超时 | 网关到上游连接问题、本地网络或代理问题 | 检查网络、代理、DNS，换网络后重试。 |
| `524` | 上游处理时间过长 | 长上下文、图像或视频生成耗时长、服务负载高 | 降低复杂度和规格，减少并发，对长任务使用异步轮询。 |

## 模型集成重点错误

| 场景 | 可能错误 | 修复 |
| --- | --- | --- |
| 图片输出格式 | `400` / `422` | `response_format` 放入 `extra_body`，不要放顶层。 |
| 图片输入不可访问 | `422` | 使用公共 HTTPS URL，或 Data URI Base64。 |
| Base64 图片过大 | `413` | 改用公共 URL 或压缩图片。 |
| 视频查询任务不存在 | `404` | 使用创建响应里的 `video_id`，不要误用前端生成的本地 ID。 |
| 视频轮询过快 | `429` | 降低轮询频率，使用指数退避。 |
| 视频尺寸或画幅非法 | `400` / `422` / `500` | 按模型文档使用 `size`、`aspect_ratio`、`num_frames`、`frame_rate`。 |
| `agnes-video-2.5-flash` 使用 2K | `400` | `size` 固定为 `"720P"`。 |
| `agnes-video-2.5-flash` 传视频参考 | `400` | 不传有效 `videos` 内容。 |

## 日志与支持

| 项目 | 建议 |
| --- | --- |
| 需要记录 | HTTP 状态码、完整响应体、请求时间、请求 ID、模型 ID、Endpoint、脱敏后的参数。 |
| 不要记录 | 完整 API Key、私有媒体 URL、用户敏感输入、Base64 原图。 |
| 联系支持 | 持续失败时将脱敏后的请求、响应、时间和请求 ID 发给 `support@agnes-ai.com`。 |
