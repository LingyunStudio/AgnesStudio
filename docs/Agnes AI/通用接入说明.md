## 接入注意事项

| 场景 | 注意事项 |
| --- | --- |
| API Key | 只应保存在服务端或安全环境变量中，不应写入前端代码、日志或公开仓库。 |
| 图片输出 | URL 输出使用 `extra_body.response_format: "url"`；Base64 输出按场景使用 `return_base64` 或 `extra_body.response_format: "b64_json"`。 |
| 图片输入 | 图生图和多图合成需要在 `extra_body.image` 中提供公开 HTTPS URL 或 Data URI Base64。 |
| 图片尺寸 | 建议使用 `1K`、`2K`、`3K`、`4K` 与 `ratio` 搭配；不要把显示器分辨率等同于模型原生尺寸。 |
| 视频生成 | 视频接口是异步任务：先创建任务，再保存 `video_id` 轮询结果。 |
| 视频轮询 | 生产环境应设置最大轮询时长；遇到 `429` 时应退避重试。 |
| 媒体 URL | 传给 Agnes AI 的图片、音频、视频 URL 需要可公开访问，并在任务完成前保持有效。 |
