# Agnes AI 速率限制与配额

资料更新时间：2026-09-03

资料来源：https://wiki.agnes-ai.com/zh-Hans/docs/tokenplan

## 访问类型

| 访问类型 | 说明 |
| --- | --- |
| 免费 / 默认用户 | 未订阅 Token Plan，且未完成企业认证的用户。 |
| 企业认证用户 | 已完成企业认证，拥有更高基准访问限制。 |
| Token Plan 用户 | 已订阅 Token Plan，拥有更高 RPM 和订阅配额。 |

同一用户可以同时拥有免费、企业认证、Token Plan 类型的 API Key；不同类型的 Key 使用不同限制池。相同类型的多个 Key 共享同一个限制池，不能通过多建 Key 叠加 RPM 或配额。

## Token Plan 配额

| Plan | 文本模型 `agnes-2.5-flash` | 图片模型 `agnes-image-2.1-flash` | 视频模型 `agnes-video-2.5-flash` |
| --- | --- | --- | --- |
| Starter | 每 5 小时 1,500 次；每周 15,000 次 | 每天 4,000 张 | 每天 500 秒 |
| Plus | 每 5 小时 7,500 次；每周 75,000 次 | 每天 4,000 张 | 每天 500 秒 |
| Pro | 每 5 小时 30,000 次；每周 300,000 次 | 每天 4,000 张 | 每天 500 秒 |

| 模型类型 | 配额计数方式 |
| --- | --- |
| 文本模型 | 按请求次数计数。 |
| 图片模型 | 按生成图片张数计数。 |
| 视频模型 | 按生成视频时长秒数计数。 |

## 图片模型 RPM

| 用户类型 | 分辨率 | 允许发起 RPM | 实际 RPM |
| --- | --- | --- | --- |
| `default` | 1K | 30 | 20 |
| `default` | 2K | 20 | 10 |
| `default` | 3K | 2 | 1 |
| `default` | 4K | 1 | 1 |
| `enterprise` | 1K | 60 | 40 |
| `enterprise` | 2K | 40 | 20 |
| `enterprise` | 3K | 2 | 1 |
| `enterprise` | 4K | 2 | 1 |
| `TokenPlan` | 1K | 120 | 100 |
| `TokenPlan` | 2K | 120 | 80 |
| `TokenPlan` | 3K | 2 | 1 |
| `TokenPlan` | 4K | 2 | 1 |

图片模型 RPM 按分辨率区分。`1K`、`2K`、`3K`、`4K` 是模型输出档位，需要和 `ratio` 配合使用，不等同于 1080p、1440p、UHD 等显示器分辨率名称。

## 视频模型 RPM

| 用户类型 | 允许发起 RPM | 实际 RPM |
| --- | --- | --- |
| `default` | 2 | 1 |
| `enterprise` | 2 | 2 |
| `TokenPlan` | 6 | 5 |

视频模型同时受 RPM 和每日视频秒数配额限制。Token Plan 用户当前视频订阅配额为每天 500 秒。

## 限制处理建议

| 情况 | 处理 |
| --- | --- |
| 达到 RPM | 等待 1 分钟窗口恢复，降低并发，加入指数退避。 |
| 达到订阅配额 | 等待配额周期刷新，或升级/调整套餐。 |
| 多 Key 并发仍被限流 | 检查这些 Key 是否属于同一类型；相同类型 Key 共享限制池。 |
| 高分辨率图片请求受限 | 降低 `size` 档位，或排队串行处理 3K/4K 请求。 |
| 视频批量生成受限 | 同时控制请求数量、轮询频率和每日生成秒数。 |
