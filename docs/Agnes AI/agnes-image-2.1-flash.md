## 请求参数

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `model` | string | 是 | 固定为 `agnes-image-2.1-flash`。 |
| `prompt` | string | 是 | 图片生成或编辑指令。 |
| `size` | string | 是 | 推荐 `1K`、`2K`、`3K`、`4K`。 |
| `ratio` | string | 否 | 支持 `1:1`、`3:4`、`4:3`、`16:9`、`9:16`、`2:3`、`3:2`、`21:9`。 |
| `image` | string[] | 图生图/多图合成必填 | 作为高级工作流输入，实际接入时放入 `extra_body.image`。 |
| `return_base64` | boolean | 否 | 文生图需要 Base64 返回时使用。 |
| `extra_body.response_format` | string | 否 | 图生图 URL/Base64 输出分别使用 `url` 或 `b64_json`。 |

## 常见错误

| 问题 | 正确处理 |
| --- | --- |
| 顶层放置 `response_format` | 改为 `extra_body.response_format`。 |
| 图生图传 `tags: ["img2img"]` | 删除 `tags`，只传 `extra_body.image`。 |
| 输入图像无法访问 | 使用公共 HTTPS URL，或改为 Data URI Base64。 |
| 请求精确显示器尺寸 | 建议使用 `size: "2K"` 与 `ratio: "16:9"`，再在下游裁剪或缩放。 |
| 图生图缺少图片 | 在 `extra_body.image` 中提供至少一张输入图。 |
