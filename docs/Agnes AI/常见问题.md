## 平台与账户

| 问题 | 答案 |
| --- | --- |
| Agnes AI 是什么？ | 面向开发者的多模态 AI API 平台，提供文本、图像、视频和多模态能力。 |
| API 可以免费使用吗？ | 核心免费模型可以使用，但仍受 RPM、配额、账户状态和活动规则影响。 |
| 免费用户有什么限制？ | 主要受 RPM 限制；达到限制后需要等待窗口恢复再调用。 |
| 多模态模型是否免费？ | 官方 FAQ 表示多模态能力可免费使用，但实际价格和优惠以模型定价页及账户账单为准。 |
| 如何开始使用？ | 注册或登录平台，在控制台生成 API Key，然后按文档调用对应 Endpoint。 |
| 如何查看使用情况？ | 在仪表板的 Usage 或 Billing 页面查看请求使用量、限制和账单信息。 |
| API Key 丢失怎么办？ | 在控制台重新生成新密钥，并删除旧密钥。 |
| 如何获得支持？ | 可联系 `support@agnes-ai.com`。提交问题时应脱敏请求、响应、时间和请求 ID。 |

## Token Plan 与限制

| 问题 | 答案 |
| --- | --- |
| 创建多个 API Key 会增加 RPM 或配额吗？ | 不会。相同类型的多个 Key 共享同一个限制池。 |
| Token Plan 用户还能使用免费 Key 吗？ | 可以。免费 Key 和 Token Plan Key 使用不同限制池。 |
| Token Plan 用户也能成为企业认证用户吗？ | 可以。免费、企业认证、Token Plan 三类 Key 按各自限制池独立生效。 |
| 企业认证是否自动拥有 Token Plan 配额？ | 不会。企业认证只提供更高基准 RPM；Token Plan 配额需要订阅。 |
| 图片配额按请求还是按图片数量计？ | 按生成图片张数计。 |
| 视频配额按请求还是按时长计？ | 按生成视频时长秒数计；视频 RPM 也同时适用。 |
| 不同类型 Key 是否共享限制？ | 不共享。限制只在相同类型 Key 之间共享。 |

## 图片生成

| 问题 | 答案 |
| --- | --- |
| 是否支持文生图？ | 支持。文生图只需要 `model`、`prompt`、`size`。 |
| 是否支持图生图？ | 支持。图生图需要在 `extra_body.image` 中传入图片数组。 |
| 图生图是否需要 `tags`？ | 不需要；不要传 `tags: ["img2img"]`。 |
| 为什么顶层 `response_format` 会报错？ | 图片模型要求把输出格式放在 `extra_body.response_format` 中。 |
| 输入图像 URL 无法访问怎么办？ | 使用公开 HTTPS URL；如果不能公开访问，改用 Data URI Base64。 |
| 请求超时怎么办？ | 图片生成可能耗时数秒到几十秒，客户端超时建议设置为 `60s-360s`。 |
| 想要 `1920x1080` 怎么办？ | 官方建议用 `size: "2K"` 和 `ratio: "16:9"` 生成，再在下游裁剪或缩放。 |

## 视频生成

| 问题 | 答案 |
| --- | --- |
| 视频接口是否同步返回成片？ | 不是。视频是异步任务，需要创建任务后轮询。 |
| 创建任务后应该保存哪个 ID？ | 新接入建议保存 `video_id`，用于查询进度和结果。 |
| 什么时候可以使用视频 URL？ | 只有 `status` 为 `completed` 且 `metadata.url` 存在时。 |
| 轮询应该多久一次？ | `agnes-video-2.5` 文档建议每 `1-2` 秒查询一次。 |
| 2.5 系列查询是否要带 `model_name`？ | 推荐所有模式都带；`keyframe` 和 `reference` 模式必须带对应 `model_name`。 |
| `agnes-video-2.5` 的 `seconds` 是数字还是字符串？ | 字符串，支持 `"4"` 到 `"12"`。 |
| `agnes-video-2.5-flash` 支持 2K 吗？ | 不支持，只支持 `"720P"`。 |
| `agnes-video-2.5-flash` 支持视频参考吗？ | 不支持有效的 `videos` 参考内容。 |
| 为什么视频 16:9 不是精确 `1280x720`？ | Flash 文档说明 2026 年 9 月实测 `720P` 的 `16:9` 输出为 `1280x704`；展示和验收应以实际文件为准。 |

## 排障

| 问题 | 优先检查 |
| --- | --- |
| `400` | 必填字段、字段位置、字段类型、模型是否支持该参数。 |
| `401` | API Key 是否完整、是否有效、Header 是否为 `Authorization: Bearer ...`。 |
| `402` | 余额、Token Plan 配额、订阅状态。 |
| `404` | Base URL、Endpoint、模型 ID、视频查询 ID。 |
| `429` | RPM、并发、轮询频率、自动重试是否过密。 |
| `5xx` | 服务端或上游临时异常，使用退避重试；持续失败再联系支持。 |
